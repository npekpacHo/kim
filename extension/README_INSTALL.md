# 🏠 Kincony Smart Control - Установка

Браузерное расширение для управления контроллерами Kincony (KC868-A4, A8, A16, A32 и др.)

---

## 📦 Быстрая установка

### Шаг 1: Запуск установщика
1. Дважды кликните на файл **`install.bat`**
2. Следуйте инструкциям на экране

### Шаг 2: Установка в Chrome
После завершения работы скрипта:

1. **Откроется страница расширений** Chrome (или откройте вручную: `chrome://extensions/`)

2. **Включите "Режим разработчика"** в правом верхнем углу
   ```
   Developer mode [  ]  →  [ ✓ ]
   ```

3. **Нажмите "Загрузить распакованное"** (Load unpacked)

4. **В окне выбора папки**:
   - Нажмите `Ctrl+L` (курсор в адресную строку)
   - Нажмите `Ctrl+V` (путь уже в буфере обмена)
   - Нажмите `Enter`

5. **Готово!** 🎉 Иконка расширения появится в панели браузера

---

## ⚙️ Первая настройка

1. Кликните на иконку расширения в панели браузера
2. Нажмите кнопку "Автопоиск"
3. Введите:
   - **Логин/Пароль** вашего контроллера Kincony (admin/admin)
4. Нажмите на круглый значок расширения внизу справа

---

## 🔄 Обновление расширения

Если вышла новая версия:

1. Скачайте новый архив
2. Запустите **`install.bat`** снова
3. Файлы автоматически обновятся
4. Перезагрузите страницу расширений в Chrome

---

## 🗑️ Удаление

### Способ 1: Через Chrome (рекомендуется)
1. Откройте `chrome://extensions/`
2. Найдите "Kincony Smart Control"
3. Нажмите **"Удалить"**
4. Запустите **`uninstall.bat`** для очистки файлов

### Способ 2: Только файлы
1. Запустите **`uninstall.bat`**
2. Следуйте инструкциям

---

## 📁 Где хранятся файлы?

Расширение устанавливается в:
```
%LOCALAPPDATA%\KIM_Extension\KIM_Extension\
```

Обычно это:
```
C:\Users\ВашеИмя\AppData\Local\KIM_Extension\KIM_Extension\
```

## ❓ Частые вопросы

### Расширение не работает после установки
1. Убедитесь, что "Режим разработчика" включен
2. Перезагрузите страницу расширений (F5)
3. Проверьте, что контроллер доступен по сети

### Не могу найти IP-адрес контроллера
1. Зайдите в настройки роутера
2. Найдите список подключенных устройств
3. Найдите устройство с именем "KC868", "ESP32" или похожим

### Chrome не открывается автоматически
- Откройте `chrome://extensions/` вручную
- Путь к папке расширения уже в буфере обмена (Ctrl+V)

### Антивирус блокирует установку
- Добавьте папку установки в исключения
- Или скопируйте файлы вручную

---

## 🛠️ Ручная установка

Если автоматический установщик не работает:

1. Создайте папку:
   ```
   C:\Users\ВашеИмя\AppData\Local\KIM_Extension\KIM_Extension\
   ```

2. Скопируйте туда все файлы расширения

3. В Chrome:
   - Откройте `chrome://extensions/`
   - Включите "Режим разработчика"
   - "Загрузить распакованное"
   - Выберите созданную папку
