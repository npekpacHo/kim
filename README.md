# 🏠 KIM - Kincony KCS IFTTT Mass Mapper

**KIM** - браузерное расширение для удобного управления контроллерами Kincony KC868.

[![Chrome](https://img.shields.io/badge/Chrome-Compatible-green.svg)](https://www.google.com/chrome/)
[![Version](https://img.shields.io/badge/version-2.14-blue.svg)](https://github.com/npekpacHo/kincony-smart-control/releases)

---

## 📋 Описание

Браузерное расширение для быстрой и удобной первичной настройки и программирования контроллеров Kincony на русском языке. Возможно позже будут и переводы.

### ⚡ Основные возможности

- 🎛️ **Быстрое управление реле** - одним кликом из панели браузера
- 🔌 **Два режима подключения** - HTTP и WebSocket
- 📊 **Мониторинг в реальном времени** - отслеживание состояния всех каналов
- ✏️ **Пользовательские названия** - переименовывайте реле как удобно
- 🎨 **Визуализация IFTTT правил** - смотрите как работает
- ⚡ **Массовый маппинг** - быстро сопоставьте входы выходам
- 🔄 **Пресеты** - создавайте правила для типовых сценариев
- 🎁 **Импорт / Экспорт** - сохраняйте конфигурации и переносите между контроллерами

---

## 🖥️ Поддерживаемые модели

- Все контроллеры KC868 с KCS версий v2 и v3
- Другие контроллеры Kincony с веб-интерфейсом тоже должны работать

## 📦 Установка

### Вариант 1: Автоматическая установка (Windows)

1. **Скачайте** последнюю версию из раздела [Releases](https://github.com/npekpacHo/kim/releases)
2. **Распакуйте** архив
3. **Запустите** `install.bat`
4. **Следуйте** инструкциям установщика

Установщик автоматически:
- Скопирует файлы в нужную папку
- Скопирует путь в буфер обмена
- Откроет страницу расширений Chrome

### Вариант 2: Ручная установка

1. **Скачайте** и распакуйте архив
2. Откройте **Chrome** и перейдите на `chrome://extensions/`
3. Включите **"Режим разработчика"** в правом верхнем углу
4. Нажмите **"Загрузить распакованное расширение"**
5. Выберите папку с файлами расширения
6. **Готово!** Иконка появится в панели браузера

## 🔧 Технические особенности

### Архитектура

- **Frontend**: Vanilla JavaScript (без фреймворков)
- **UI**: Чистый HTML/CSS
- **Хранилище**: Chrome Storage API
- **Коммуникация**: WebSocket / XMLHttpRequest

### Оптимизации

- Умное управление опросом состояния
- Optimistic UI для мгновенного отклика
- Блокировка конфликтующих запросов
- Автоматическое переподключение при обрывах

### Безопасность

- ✅ Все данные хранятся локально в браузере
- ✅ Прямое подключение к контроллеру (без облака)
- ✅ Нет отправки данных на сторонние серверы
- ✅ Open source - код доступен для проверки

## 🛠️ Для разработчиков

### Структура проекта

```
kincony-smart-control/
├── manifest.json         # Манифест расширения
├── content.js            # Основная логика
├── popup.html            # HTML интерфейса
├── popup.js              # Логика popup
├── settings.html         # Страница настроек
├── settings.js           # Логика настроек
├── styles.css            # Стили
├── icon.png              # Иконки расширения
├── presets/              # Пресеты
│   ├── bathroom_vent.js  # Проветривание
│   ├── global_master.js  # ЦУ освещением
│   └── local_master.js   # Мастер-клавиша
├── installer/            # Установщик для Windows
│   └── install.bat
└── README.md
```

### Локальная разработка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/npekpacHo/kim.git
```

2. Откройте Chrome и перейдите на `chrome://extensions/`

3. Включите "Режим разработчика"

4. "Загрузить распакованное расширение" → выберите папку проекта

5. При изменениях нажимайте "Обновить" на странице расширений

### Требования

- Chrome 88+
- Контроллер Kincony с веб-интерфейсом
- Локальная сеть (контроллер должен быть доступен)
